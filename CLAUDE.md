# simulink-maglev-pid-control

MECH1320 magnetic-levitation PID control: MATLAB analysis in `src/`, Simulink models in `models/`, write-up in `reports/`.

## Rules
- `.slx` models are binary: do not hand-edit or reformat them; describe model changes in prose for the user to apply in Simulink.
- MATLAB code in `src/analysis_code.m` can be edited; keep it runnable top to bottom.
- Coursework: do not rewrite results or reports without being asked.
